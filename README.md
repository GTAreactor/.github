# GTAreactor organization profile

This repository holds the public GitHub profile of GTAreactor.

- `profile/README.md`: the text shown on the [organization page](https://github.com/GTAreactor)
- `profile/history.md`: the history of GTAreactor in German
- `profile/history.en.md`: the same history in English
- `profile/screenshots/`: images used in the history

The history only covers what we know so far. Corrections and additions are welcome as pull requests.
